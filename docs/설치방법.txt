7구역 — 폰에 설치하기 (알파 5.6.2)

이 폴더는 "홈 화면에 추가"로 설치하는 웹앱(PWA)입니다.
폰에서 파일을 직접 열어서는 설치되지 않고, HTTPS 주소로 올려 두어야 합니다.

1. 이 폴더의 파일을 전부 웹 호스팅에 올립니다(설치방법.txt 는 올리지 않아도 됩니다).
   - 정적 파일을 올릴 수 있고 주소가 https:// 로 시작하는 곳이면 됩니다.
   - 올린 뒤 index.html 이 있는 주소를 폰 브라우저로 엽니다.

2. 폰에서 설치합니다.
   - 안드로이드(Chrome): 오른쪽 위 메뉴 > "홈 화면에 추가" 또는 "앱 설치"
   - 아이폰(Safari): 아래 공유 버튼 > "홈 화면에 추가"

3. 홈 화면의 7구역 아이콘으로 열면 주소창 없이 전체 화면으로 실행됩니다.
   한 번 연 뒤에는 인터넷이 없어도 열립니다.

알아 둘 점
- 진행은 그 폰의 브라우저 저장소에 남습니다. 브라우저 데이터를 지우면 함께 사라지니
  기록 > 저장·설정의 "저장 코드 복사"로 가끔 백업해 두세요.
- 계정 저장(기기 간 이어하기)은 Claude 에 게시된 페이지에서만 동작합니다.
  설치형으로 옮길 때는 게시된 페이지에서 저장 코드를 복사해 설치형에서 불러오면 됩니다.
- 새 버전 내기: 새로 받은 폴더의 파일을 같은 주소에 덮어 올리면 됩니다.
  설치된 앱은 열 때, 30분마다, 화면으로 돌아올 때 새 버전을 확인하고
  맨 위에 "새 버전이 나왔다 · 지금 업데이트" 띠를 띄웁니다. 누르면 진행을 저장하고 새 버전으로 다시 엽니다.
  "나중에"를 누르면 그 버전은 다시 묻지 않고, 앱을 다음에 열 때 자동으로 바뀝니다.
- 글꼴은 인터넷이 있을 때 받아 옵니다. 오프라인에서는 폰의 기본 글꼴로 보입니다.
