# 배경 음악 음원

이 폴더에 아래 이름의 파일을 두면 빌드(`node build.js`)가 게임 파일 안에 끼워 넣는다.

| 파일 이름 | 나오는 때 |
|---|---|
| `day`   | 낮 |
| `night` | 무리가 온 밤 |
| `dread` | 변이체가 온 밤, 위험 11단계부터 |

- 확장자: `.ogg` `.mp3` `.m4a` `.wav` (같은 이름이 둘이면 이름순으로 앞의 것)
- 셋 다 없어도 되고 하나만 있어도 된다. 없는 곡은 `day` 로 대신한다.
- 한 파일은 4MB 까지. 넘으면 빌드가 멈춘다. 1분 안팎, 96~128kbps 면 1MB 쯤이다.
- 끊김 없이 되풀이되므로 처음과 끝이 이어지는 음원이 좋다. `.ogg` 가 이음매가 가장 깨끗하다(`.mp3` 는 파일 앞뒤에 짧은 무음이 붙는다).
- 음원이 하나라도 있으면 합성 음악은 쓰지 않고, 배경 음악의 기본값이 "켬"이 된다.

**넣기 전에 확인할 것**: 이 저장소는 공개돼 있다. 게임에 넣어 배포해도 되는 음원인지(상업적 이용, 출처 표기 조건) 반드시 확인한다.
